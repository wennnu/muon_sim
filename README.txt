#Muon Lifetime Measurement Simulation
This was part of an undergraduate student chose physics project. The muon
lifetime measurement was conducted using the Muon Physics equipment from TeachSpin. In addition to the experimental analysis, I wanted to see if I can
simulate the environment in Geant4, which I followed a tutorial on (YouTube)[https://youtu.be/Lxb4WZyKeCE?si=gfHM5D6SQl9rRb0q] for the
basic set ups. The code is fully written in C++. 

##Packages required
Both of the Geant4 and the ROOT packages need to be installed. ROOT is needed
for data visulizations.
